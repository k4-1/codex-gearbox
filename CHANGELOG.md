# Changelog

Release notes are generated from merged pull requests and published with each
GitHub release. The latest history is available on the
[GitHub Releases page](https://github.com/k4-1/codex-gearbox/releases).

To keep entries readable for users, pull requests should use a plain-language
title and include a short **User-facing release note**. Maintainers assign one
release label such as `enhancement`, `bug`, `security`, `privacy`,
`maintenance`, or `ignore-for-release` before merging.
